# chapter-bank reference — 🗂️ source pages

Read this file before creating or updating any source / reference page.

## One page per source [HARD] — and check before you mint

- **Titled with the full citation** — `[[Real, T. (2022). Us: Getting past you and me to build
  a more loving relationship. Rodale Books.]]` — optionally aliased to an `@{shortkey}` node.
- **Run on_create_check BEFORE proposing a new source page.** Near-duplicate citations are a
  known trap: capitalization/punctuation variants of the same citation, a descriptive-title
  "concept" page wrongly stamped as a source page, and `…`-suffixed stubs have all forked this
  rule in practice (the Real 2022 three-way, resolved Jul 12 2026). Author-name variants
  (`Scott` / `J.C. Scott` / `Scott 1998`) must match.
- If a **concept zettel about the source** exists (e.g. "Real (2022), Us — the relational
  critique of individualism"), it stays a **concept zettel** and links the source page — it is
  not a second source page.

## The field set (Jul 11 2026 source-page wave — the working format)

`Title::` · `Source type::` · `Full citation::` · `Authors::` · `Year::` · `DOI / URL::` ·
Zotero links · `CiteKey:` · `Literature Category:` · `Read status::` · `Project relevance::` ·
`Related concepts::` · **Why I am reading this** · **Central argument** · `Annotations::` ·
**Key concepts** · **Source notes** (abstract, quotes, takeaways) · **My responses** (QUEs,
claims, EVD) · `Zettels::` (the 📇 notes this source feeds) · **Possible uses** ·
**Limits and cautions**.

## The five-field debate map (layered onto the same page)

1. **`Argument::`** — what the author claims, in your summary.
2. **`Aligns-with::` / `Tensions-with::`** — edges to other sources **already in your graph**.
   This makes the literature bank an argument among sources, not a summary pile.
3. **`Gaps::`** — what the author does not address.
4. **`Opens::`** — what the gap opens → a QUE generator (reading-QUE in literature; a gap the
   book could answer → argument-QUE in the discourse graph).
5. **Book footprint** — free via Linked References; every 📇/EVD/chapter block citing the page
   shows there automatically, two-way. No field to maintain.

**Automation ceiling [HONEST].** The footprint auto-fills. `Argument::` and `Gaps::` are
**drafted** from source text *you* provide; align/tension **edges are proposed** against your
existing literature. **You confirm every one** — shared backlinks is a signal, shared *meaning*
is not.

## Discussion blocks → evidence lane

Discussion written on the source page is the **literature evidence lane** — it becomes
`EVD —` nodes (via the gate) under the claims it supports.

## Handoffs
