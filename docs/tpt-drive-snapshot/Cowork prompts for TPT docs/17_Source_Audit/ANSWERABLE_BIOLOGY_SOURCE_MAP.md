# ANSWERABLE BIOLOGY — SOURCE MAP

Canonical inventory of every source deck in the Answerable Biology corpus: what exists, where it sits in the 20-cycle year, what it contains verbatim, and what is missing or flagged.

## What this file is

This is an **internal build document** — the primary reference for every other document in the Answerable Biology build. It is not teacher-facing and not for sale. It merges the three extraction batches (`work/source_map_part1.md`, `part2.md`, `part3.md`) into one file, in cycle order, with formatting harmonized but **no content abridged** — all verbatim deck material, three-tier questions, pattern-breaks, links, anecdotes, and anomaly logs from the batch files are preserved in full. Downstream documents (Year Arc, Unit Guides, Activities & Labs, Standards Alignment, TPT product system, Supplies, Fiddles) are built from this file without rereading the extracted decks.

How to read it:

1. **Master table** — one row per deck (28 rows: 27 decks in corpus + 1 known-missing deck), with cycle, unit, role, short essential claim, critical aspects, key activities, external-link count, and flags.
2. **Per-deck entries** — the full unabridged entries, merged in cycle order. Field labels are bolded uniformly; Part 2/3 entries otherwise read exactly as extracted.
3. **Cross-batch observations** — the three batches' own cross-deck notes, verbatim.
4. **Structural findings** — the resolved cycle → unit → deck mapping (including where Classifying Organisms sits and how 19 units cover 20 cycles), the CORE/EXTEND pattern, deck generations, duplicates, missing sources, and naming conflicts.
5. **All flags** — every flag from the three batches, consolidated by label.

Flag labels used (from BUILD_BRIEF): `REVIEW WITH KATHERINE` · `SOURCE NOT YET LOCATED` · `RIGHTS REVIEW NEEDED` · `LINK NEEDED` · `EXAMPLE NEEDED` · `GAP — NOT IN SOURCE NOTES`.

### 4.2 The CORE/EXTEND pattern

- **Five multi-deck cycles**, exactly as BUILD_BRIEF lists: Cycle 07 (core + 1 extend), Cycle 08 (core + 1 extend), Cycle 12 (core + 1 extend — core missing from corpus), Cycle 13 (core + 1 extend), Cycle 16 (core + 3 extends). - The Unit Descriptions frames every multi-deck unit as **"choose by pace"**: "Use the core deck alone for a resistant-learner pace, or add the second to extend." The core deck always secures the foundational idea (carrying capacity; cell theory; the meiosis process; Mendelian inheritance; what a mutation is); the extend deck(s) add the system, the tool, or the application (succession; organelles-as-factory; reproduction & variation; Punnett squares & carriers; biotech / disorders / stem cells).
