Purpose: Keep every photograph, diagram, and scientific visual in the commercial curriculum traceable, instructionally useful, and legally reusable.

# Visual Rights and Credits Guide

Visuals serve conceptual work. Do not add an image merely to make a slide look polished.

Use a visual when it helps make a critical aspect perceptible, establishes a contrast, shows a real organism or phenomenon, makes scale visible, clarifies a mechanism, supplies evidence, supports exploration, reduces unnecessary verbal explanation, or makes a question more answerable from evidence.

## Source priority

Prefer public domain / CC0 first, then U.S. government public-domain material, then CC BY. Treat other licenses as review-required.

Do not treat "free online," "free for teachers," or "open access" as permission for commercial redistribution.

Do not use CC BY-NC in a product sold on TPT.

Do not use ND material when the visual will be cropped, labeled, altered, or otherwise modified.

Flag ShareAlike material for `RIGHTS REVIEW NEEDED` unless a downstream licensing plan is clear.

Google Images may help locate a source. It is never the source record. Trace the asset to its originating page and license.

## Preferred repositories

- Smithsonian Open Access — use assets specifically marked CC0.
- NOAA — public-domain imagery unless the item credit/caption says otherwise; verify the individual item.
- USGS — USGS-authored material is generally public domain; check for third-party credits.
- CDC PHIL — use items explicitly marked Public Domain.
- NCI Visuals Online — use items explicitly marked Public Domain.
- Wikimedia Commons — prefer Public Domain/CC0, then CC BY; inspect every file page.
- NLM and similar repositories — item-level rights review.
- OpenStax — manual/exception-only under the current source standard because licensing and generative-AI ingestion terms require separate attention.

## Visual Source Register

Maintain one record for every placed visual with:

- Course
- Unit
- Cycle
- Lesson
- Slide number or location
- Visual purpose / critical aspect served
- Asset description
- Source institution
- Creator/photographer if known
- Source URL
- License / public-domain status
- Commercial reuse permitted?
- Modification permitted?
- Attribution text
- Modified/cropped/labeled?
- Local filename
- Date verified
- Rights-review status

If a rights-cleared visual cannot be found quickly, insert a named placeholder and continue: `VISUAL NEEDED — [purpose] — RIGHTS-CLEARED SOURCE NEEDED`.

## Credits

Generate compact unit/bundle credits from the register. Do not reconstruct credits manually at publication time.

`RIGHTS REVIEW NEEDED` — every existing deck visual whose provenance is not already in the register.
