# TPT Product Architecture — Answerable Biology

Purpose: the selling structure — what each TPT product contains file by file, how the free unit, the 19 individual units, the four quarter bundles, and the full-year bundle relate without overlap-resentment or duplicated documents, and which rights verdicts gate what.

This is a seller-side system document (Katherine-facing, not buyer-facing). Buyer-facing listing copy for the 19 units already exists in `Answerable_Biology_Unit_Descriptions.md` and is authoritative for unit framing; bundle listing copy is drafted from it. All rights calls below follow the Activity Source and Rights Audit verdicts exactly; all deck facts follow the Source Map.

---

## 1. The product ladder

| Tier | Product | What it is for |
|---|---|---|
| Free | Free Ecology Unit (Cycle 02 + Year Arc + Start Here + free unit guide) | Demonstrates the whole system on one genuinely teachable cycle; every paid listing links back to it and it links forward to all of them |
| Paid, single | 19 individual unit listings | Serves teachers searching for one topic ("photosynthesis NGSS"); each is complete enough to teach alone |
| Paid, bundle | Quarter 1–4 Bundles | A quarter of cycles plus the full implementation infrastructure — the tier for teachers adopting the system, not sampling a topic |
| Paid, bundle | Full-Year Bundle | Everything: all decks, all documents, the complete system |

The ladder logic: the free unit converts browsers into believers; individual units capture topic searches and link to their quarter bundle; quarter bundles carry the infrastructure that makes the system a system; the full-year bundle is the destination. Every product description ends with links up and down the ladder.

Pricing at every tier is Katherine's decision — no prices appear in this document. REVIEW WITH KATHERINE (price points for all seven bundle-tier products and the 19 units; the Unit Descriptions file already marks "your price goes where marked").

## 6. Canonical shared documents — one copy, never forked

The rule, identical to the supply workbook's "edit only MASTER": every document exists as exactly one canonical file at the path in section 3.1 (plus the Year Arc, Start Here, and Ecology Unit Guide). Products carry exports (PDF for reading documents, xlsx for the supply workbook, pptx for decks), regenerated from the canonical file at packaging time. No product ever gets a hand-edited variant — a bundle-specific copy is how two versions of the revision prompt end up in the wild.

Consequences:

- When a canonical doc changes, re-export it into every product the matrix (section 7) says carries it, and use TPT's product-file update so existing buyers re-download. The matrix is the update checklist.
- The free unit's "Cycle-02 section" guide is an export slice of the Ecology Unit Guide, produced by a repeatable cut (section 2 + the section-1 table), not a separately maintained document.
- Documents link to each other by exact title (Start Here, Year Arc, Master Agenda, and so on), never by folder path, so exports work in any product's zip. Folder-path links that exist in the canonical files are converted to plain titles at export/packaging time — that conversion is a step on the packaging checklist, alongside the matrix-driven re-export above.
- The internal build documents are never packaged in any product: everything in `/root/ab_build/output/17_Source_Audit/` (Source Map, Teaching Reasoning Extraction, Activity Source and Rights Audit, Broken Link Report), `/root/ab_build/output/18_Video_Plan/Video_Setup_Plan.md`, `BUILD_BRIEF.md`, and `Answerable_Biology_Unit_Descriptions.md` (it is listing copy, pasted into TPT, not a file buyers receive).
