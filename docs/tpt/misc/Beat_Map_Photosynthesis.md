## DRIFT RISKS & MITIGATIONS

| Risk | Where It Appears | Mitigation Applied |
|------|-----------------|-------------------|
| Structure before function | Slides 22–23 (chloroplast) | Causal question on 22 ALWAYS precedes structure names on 23 |
| "Dark reactions" misconception | All of Run 3 | Term eliminated completely; replaced with "Building Reactions (Calvin Cycle)" |
| Light as reactant | Slides 13–18 | Gold callout on 13, forced-choice on 17, explicit misconception break on 18 |
| Stage 2 = night only | Slides 30–35 | Forced choice on 35 with fill-in tracing dependence on Stage 1 carriers |
