## How to read this table

**This table reports. It does not judge.** An absence in the coordination
column is a measurement, not a verdict. A standard addressed without a
coordination structure — because the content carries no compensatory
relationship and no genuine conflict case — is a design decision, not a gap.
The table tells you which one you are looking at; it does not tell you which
one it is.

**The reason column is blank wherever the deck does not state a reason.**
Blank means *not stated*. It does not mean *no reason*. Nothing in this
column is inferred, guessed, or written by the script.

The three structures are different kinds of object, and that decides what
can be retrofitted:

| Structure | Kind | Retrofit |
|---|---|---|
| Stock-and-flow model | a representation | can be ADDED to any cycle whose content accumulates |
| Compensatory pair | a case set | must be FOUND in the content; cannot be manufactured |
| Conflict case | a single case with opposing pulls | must be FOUND |

The what-if is **not** a fusion device. It tests coordination rather than
creating it, and it must be individual and written or the diagnosis is empty.
It is reported here as the companion to whichever structure a cycle carries.
